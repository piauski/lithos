# Lithos

Simple 3d Voxel game written in C using [raylib 6.0](https://github.com/raysan5/raylib/releases/tag/6.0) and [nob.h](https://github.com/tsoding/nob.h) for building.

## Quickstart
Using nob.h, building is quick and painless. Build and run by the following:
```
$ cc nob.c -o nob
$ ./nob -run
```
